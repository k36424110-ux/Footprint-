# Footprint BTC (multi-bourses)

Site statique : aucune installation, aucun serveur. Le navigateur se connecte directement aux flux publics de Binance Futures, Bybit, OKX et Coinbase.

## Déploiement
1. Crée un dépôt GitHub et envoie `index.html`, `render.yaml` et `README.md` à la racine.
2. Sur render.com : New > Static Site > choisis le dépôt. Build command : vide. Publish directory : `.`
3. Ouvre le lien fourni par Render.

Outil d'analyse uniquement, pas un conseil financier.
